# Проверки Gemini API — версия 1.2.0

Дата локальной проверки: 17 ноября 2026. Исходная база — `4034087` (main после исправления SDK workflow), работа выполнена в `feature/gemini-api`.

## Автоматические проверки

Локальная команда, JDK 17, SDK 35 / Build Tools 35.0.0, Gradle 8.11.1:

```bash
./gradlew --no-daemon :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

Результат: **57 тестов, 0 failures, 0 errors, 0 skipped**, debug APK создан, lint без ошибок. 21 новый Gemini-тест и 36 прежних тестов геометрии, поиска, жестов, кэша и жизненного цикла. Lint сообщает 9 предупреждений: 6 о доступных обновлениях закреплённых AndroidX-зависимостей, один неиспользуемый ресурс атрибуции и две рекомендации Bitmap KTX. Эти предупреждения не отключены.

| Проверка | Что подтверждает |
|---|---|
| generateContent/model | Точный путь `gemini-3.5-flash-lite:generateContent`, POST, x-goog-api-key только в заголовке, отсутствие Interactions/sampling-параметров/Search в переводе |
| JSON перевода | Сопоставление по id независимо от порядка, отклонение пропущенных/повторных/чужих id, неверных типов, пустых и повреждённых ответов |
| Завершение модели | Отклонение safety-блокировки, MAX_TOKENS, пустых candidates/текста |
| Изображение | Схема Google Search с переданным фрагментом; преобразование нормализованных координат по размерам отправленного изображения и проверка границ |
| Grounding | Связи chunk/support, UTF-8 byte offsets кириллицы, сохранение HTML Suggestions, безопасные HTTPS-ссылки; отсутствие подтверждения поиска без корректных метаданных |
| HTTP ошибки | MockWebServer: 400 invalid key, 401/403, 404, 429, 503; фиксированные сообщения без сырого ответа/ключа |
| Сеть и повторы | Один повтор 5xx и успешный следующий ответ; отказ без повторов при разрыве соединения/тайм-ауте; запрет redirect и отсутствие запроса при пустом ключе |
| Отмена | Получены HTTP-заголовки, чтение тела ещё ожидает: отмена coroutine прекращает Call, поздний результат не доставляется |
| Смена провайдера | Кэш раздельный по провайдеру/модели/языкам; смена конфигурации отзывает старый token и вызывает остановку активной сессии |

Все HTTP fixtures синтетические, ключ `test-key-not-real` не является настоящим секретом. MockServer слушает локальный loopback; CI не обращается к Gemini. Тесты парсера и протокола не подтверждают поддержку конкретной модели сервисом Google.

## Документация API и пределы проверки

Попытка открыть актуальную документацию `ai.google.dev` в этой облачной среде отклонена сетевым прокси (CONNECT HTTP 403). При первоначальной подготовке домен был добавлен в черновик сетевых настроек. Повторная проверка 17 ноября после публикации среды пользователем также получила CONNECT HTTP 403 для страниц моделей, structured output и Google Search. Обход ограничения не выполнялся.

Схема generateContent сопоставлена с доступными официальными исходниками [googleapis/python-genai — google/genai/types.py](https://github.com/googleapis/python-genai/blob/main/google/genai/types.py): `GenerateContentConfig.response_json_schema`, `GoogleSearch`, `GroundingMetadata`, `GroundingSupport`, `Segment` (UTF-8 bytes) и `SearchEntryPoint.rendered_content` (HTML для WebView). Это проверяет структуру полей, **не подтверждает доступность gemini-3.5-flash-lite, её лимиты, поддерживаемые функции или актуальные условия отображения Suggestions**. Полная сверка с документацией модели остаётся невыполненной.

Ссылки для такой проверки:

- [Модели Gemini](https://ai.google.dev/gemini-api/docs/models)
- [REST generateContent](https://ai.google.dev/api/generate-content)
- [Structured outputs](https://ai.google.dev/gemini-api/docs/structured-output)
- [Google Search grounding и Search Suggestions](https://ai.google.dev/gemini-api/docs/google-search)
- [API-ключи](https://ai.google.dev/gemini-api/docs/api-key)

Идентификатор модели оставлен ровно по заданию. Нет замены на другую модель или локальный перевод при ошибке. HTTP 404 сообщает о недоступности указанной модели; 403 — об ошибке ключа/доступа. Настоящий ключ в среду не передавался; live API-запросы не выполнялись.

## Ручной чек-лист Android 15 — НЕ ВЫПОЛНЕН

Использовать собственный ключ только в приложении, устройство с разрешёнными overlay и захватом всего экрана. Отметки ниже оставлены пустыми намеренно.

1. [ ] **Ввод/сохранение.** Поле скрыто по умолчанию; показ/скрытие работают. В авиарежиме сохранение успешно, поле очищается, режим Gemini активируется. Проверка подключения отдельно сообщает отсутствие сети. После пересоздания Activity несохранённый ввод исчезает. Ввод не попадает в saved state, логи, crash reports.
2. [ ] **Повторный запуск.** Закрыть процесс, открыть снова, затем перезагрузить телефон: режим и ключ сохранены, повторный ввод не нужен. Проверить AES-GCM файл в no-backup storage debug-приложения: нет plaintext, при двух сохранениях разные IV. Проверить отсутствие секрета при backup/device transfer. После очистки данных/переустановки ключ отсутствует; повреждение ciphertext/удаление Keystore alias даёт понятную ошибку и возможность заново сохранить.
3. [ ] **Подключение.** Рабочий ключ с доступом к точной модели → «Подключение проверено». Проверить ключ без доступа к API/модели; выбранная модель и режим сохраняются. Сверить реальные поля structured output/GoogleSearch и правила Suggestions с текущими документами Google.
4. [ ] **Перевод Gemini.** Английский → русский, несколько связанных блоков: одно пакетное обращение без Search и изображения, текст привязан к своим координатам. Проверить кириллицу/другой исходный язык через изображение и приблизительную маркировку. При отсутствии текста, заблокированном и усечённом ответе нет ложного полного перевода.
5. [ ] **Размытие.** На Android 15 оригинальные надписи размыты, перевод, кнопка и controls резкие, фон вне блоков резкий. Проверить светлый/цветной/фотографический фон и тесные блоки. Отдельно Android 10–11 — CPU fallback; проверить отказ hardware blur на Android 15.
6. [ ] **Координаты.** Сравнить позицию каждого перевода с оригиналом: portrait/landscape, status/navigation bars, вырез, масштаб текста. Для длинного перевода работает читаемый минимум, перенос, многоточие и полный просмотр. При пересечении блоков доступен полный список.
7. [ ] **Скрытие.** Один tap убирает результат, живой экран принимает касания. Новый tap снимает свежий кадр. Отмена во время OCR/HTTP не возвращает старый результат.
8. [ ] **Поиск текста.** Долгое нажатие → рамка → OCR → редактирование → Gemini. Проверить пустой и ручной запрос, кириллицу, `+ & #`, переносы. Находящиеся в OCR-тексте инструкции рассматриваются как данные. Проверить связанные источники и честную отметку без groundingMetadata.
9. [ ] **Поиск изображения.** Сравнить preview с выделенными пикселями. В запросе только фрагмент и введённый запрос, внерамочная часть отсутствует. При неоднозначном содержимом ответ признаёт неопределённость. Сохранение PNG и передача через chooser/Lens по-прежнему работают; нет обещания найти оригинал картинки.
10. [ ] **Источники/Suggestions.** Номера соответствуют фрагментам ответа. HTTPS-ссылки и «Открыть поиск в Google» открывают внешний браузер; случай без браузера обработан. HTML Google отображается полностью с прокруткой, ссылки работают. JavaScript, file/content URI, bridge, autofill и автоматическая навигация недоступны. Сверить визуальный блок с требованиями Google.
11. [ ] **Ошибки сети/ключа.** Авиарежим, потеря сети после отправки, медленный ответ, неверный ключ, 403/404/429/5xx: понятная ошибка, UI не зависает, провайдер/модель не меняются. Нет бесконечных повторов и секретов в диагностике.
12. [ ] **Замена/удаление.** Во время длительного запроса сохранить другой ключ/удалить ключ: текущий запрос отменён, старый результат не появляется, сессия остановлена. После нового запуска работает только новый ключ или показывается «Ключ не задан». Проверить удаление во время «Проверить подключение».
13. [ ] **Поворот/остановка.** Повернуть во время capture, OCR, Gemini HTTP, выделения и результата. Старые снимки закрыты. Смена режима/языка также отзывает текущие запросы. Закрытие результата/поиска, home, stop notification, системный отзыв, блокировка не оставляют overlay; новое согласие требуется после остановки projection.
14. [ ] **Обычный режим.** Выбрать поддерживаемую пару, загрузить модель, перевести без сети и ключа. Кнопка/рамка/blur/полный просмотр работают. Текстовый поиск открывает браузер, PNG передаётся/сохраняется, в Gemini нет обращений. Смена провайдера не использует чужой кэш. Повторить базовые сценарии из SEARCH_VALIDATION.md.

Keystore, сохранение после reboot, GPU blur, фактические координаты/MediaProjection, WebView Suggestions и live API требуют устройства; JVM-тесты их не заменяют.
