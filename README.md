# Screen Translator

Android-приложение на Kotlin для перевода текста и поиска по выделенной области экрана. Версия **1.2.0** добавляет **Gemini API** и общий размытый фон под переводом. Основное устройство — Android 15; minSdk 29 (Android 10), compileSdk/targetSdk 35.

## Режимы

| | Обычный | Gemini API |
|---|---|---|
| Перевод | ML Kit на устройстве | Gemini 3.5 Flash-Lite |
| OCR и координаты | Bundled Latin OCR | Тот же OCR; для других исходных языков — анализ изображения с приблизительными координатами |
| Поиск текста | Исправляемый запрос → внешний Google Search | Исправляемый запрос → Gemini с Google Search grounding |
| Поиск изображения | Передача фрагмента внешнему приложению или сохранение | Фрагмент и запрос → Gemini; передача/сохранение также доступны |
| Интернет | Загрузка локальных моделей и внешний поиск | Каждый запрос Gemini; расходуется квота ключа пользователя |

Режим, языки и положение кнопки сохраняются в DataStore. Автоматического перехода между провайдерами или моделями при ошибке нет. Используется только `gemini-3.5-flash-lite`; выбрать другую модель в этой версии нельзя.

## Gemini: ключ и подключение

1. На главном экране выберите **Gemini API**.
2. Введите собственный **Gemini API-ключ**. Поле скрыто по умолчанию, кнопка «Показать» открывает введённые символы.
3. Нажмите **«Сохранить»**. Это отдельная операция без сети; она активирует и запоминает режим Gemini, очищает поле ввода. Сохранённый ключ автоматически используется при следующих запросах, открытиях приложения и после перезагрузки телефона.
4. **«Проверить подключение»** отправляет короткий generateContent-запрос к выбранной модели и использует небольшую часть квоты. Сохранение ключа не означает проверку доступа.
5. Для замены введите новый ключ и сохраните. **«Удалить ключ»** удаляет шифротекст и ключ шифрования. Замена/удаление останавливает текущую сессию и отменяет HTTP-запросы; после изменения запустите переводчик снова.

API-ключ шифруется **AES-256-GCM** ключом из **Android Keystore**, с новым случайным IV при каждом сохранении. Атомарный файл с шифротекстом находится в приватном `noBackupFilesDir`; резервное копирование и перенос данных дополнительно исключены в манифесте и extraction rules. Обычные настройки хранятся отдельно. Поле ввода использует `remember`, не `rememberSaveable`; незавершённый ввод не переживает пересоздание Activity. Сохранённый секрет не подставляется обратно в поле.

Повторный ввод нужен после удаления ключа, очистки данных, переустановки или невозможности расшифровать сохранённые данные. В последнем случае приложение предлагает сохранить ключ заново. В сборке, BuildConfig, GitHub Actions и CI секрет не нужен. Не добавляйте свой ключ в исходники, тесты или GitHub Secrets этого проекта.

В режиме Gemini текст и выбранные изображения обрабатываются сервисом Google. Требуется интернет, используется квота вашего API. Доступность модели и её функций зависит от Google и проекта владельца ключа. Проверка реального API в этой среде не выполнялась; ограничения сверки документации перечислены в [GEMINI_VALIDATION.md](GEMINI_VALIDATION.md).

## Захват и перевод

1. Выберите языки, нажмите **«Запустить переводчик»**. В обычном режиме дождитесь загрузки моделей; по умолчанию нужен Wi-Fi, мобильную загрузку можно разрешить отдельно.
2. Разрешите отображение поверх приложений, уведомления (Android 13+) и захват **всего экрана**. Отказ от уведомлений не запрещает foreground service; остановка остаётся доступна в приложении и системном интерфейсе.
3. Откройте нужное приложение. Короткое нажатие на плавающую кнопку получает свежий снимок без собственных overlay, распознаёт и переводит текст. Во время обработки повторное нажатие отменяет операцию.
4. На статичном исходном снимке **размыты только области надписей**. Цвета фона сохраняются, поверх идёт чёткий перевод с лёгким затемнением. Остальная картинка резкая. Оба провайдера используют один renderer.
5. Размер текста подбирается с переносами и минимумом 10 dp; блоки не расширяются на соседей. Если текст не помещается, нажмите блок для полного перевода. Нажатие на свободную область показывает все переводы. Пересекающиеся OCR-блоки также доступны в полном просмотре.
6. Одно нажатие на **«×»** удаляет результат и возвращает живой экран. Следующее нажатие получает новый кадр. Кнопку можно перетаскивать.

Размытый фон готовится один раз для снимка вне главного потока: Android 12+ — RenderEffect/HardwareRenderer, Android 10–11 и отказ аппаратного пути — уменьшенный bitmap и совместимый CPU blur. `onDraw` только совмещает слои и ограничивает фон прямоугольниками. Полный снимок при подготовке размытия даёт запас пикселей за границами каждого блока.

Для стандартного Gemini-перевода локальный OCR передаёт **только текстовые блоки**, каждому назначается `block_N`. Блоки группируются (до 64 / 12 000 символов за запрос), перевод получают в structured JSON Schema и размещают по исходным OCR-координатам. Неизвестные/повторные/пропущенные id, неверные типы, пустые переводы и незавершённые ответы отклоняются целиком: частичный результат не показывается. Текст экрана в инструкции модели считается данными, включая находящиеся внутри него команды. Google Search для перевода не подключается.

Обычный режим предлагает шесть исходных языков: английский, немецкий, французский, испанский, итальянский, португальский; 59 целевых языков закреплённой ML Kit Translation. OCR входит в APK, модели перевода загружаются отдельно. После загрузки выбранная пара работает без сети. Для ML Kit предполагаются совместимые Google Play services; прошивки без них не проверены.

В Gemini можно выбрать те же 59 языков в обоих направлениях. Для исходного языка вне этих шести используется отдельный путь анализа изображения: при переводе всего экрана отправляется весь снимок, при распознавании выделения — только фрагмент. Ответ содержит текст, перевод и проверяемые нормализованные координаты `[left, top, right, bottom]` в диапазоне 0–1000. Они пересчитываются из фактически отправленного изображения в исходный bitmap и помечаются как приблизительные. Качество распознавания и переводов зависит от языка и изображения. Одинаковые языки не допускаются. После переключения на обычный режим выберите поддерживаемый исходный язык, если ранее был выбран другой.

## Поиск на экране

1. Удерживайте плавающую кнопку. Перетаскивание отменяет долгое нажатие. Открывается свежий снимок.
2. Проведите рамку, переместите её за середину или измените размер за края/углы. Маленькую область нужно увеличить. Координаты учитывают масштаб вписанного снимка и поля.
3. **«Искать текст»** распознаёт только выбранный фрагмент и открывает редактируемый запрос. Можно ввести запрос вручную. В обычном режиме «Искать в Google» открывает браузер; в Gemini кнопка «Искать через Gemini» отправляет запрос с Google Search tool.
4. **«Поиск по изображению»** показывает выбранные пиксели без рамки/затемнения. В Gemini введите запрос и нажмите «Искать через Gemini»: отправятся только этот фрагмент и запрос. Модель получает инструкцию обозначать неоднозначность распознавания.
5. Gemini показывает ответ на русском, источники и фрагменты ответа с номерами источников. Связи берутся из `groundingChunks` и `groundingSupports` (в том числе UTF-8 offsets). Без корректных связей показывается **«Ответ модели без подтверждённого веб-поиска»**. Подключённый tool сам по себе не считается доказательством поиска.
6. Источники открываются по HTTPS во внешнем браузере; доступно **«Открыть поиск в Google»**. Если API вернул `searchEntryPoint.renderedContent`, предоставленный HTML показывается без изменения в отдельном системном WebView: JavaScript, мосты, доступ к файлам/content URI, DOM storage, cookies и кэш отключены. Автоматические переходы блокируются; нажатия на HTTPS-ссылки открывают браузер.
7. **«Перевести»** на экране выделения использует текущий провайдер и показывает полный перевод фрагмента. **«Закрыть»** возвращает исходное приложение; «Назад» из редактора/результата/предпросмотра возвращает к рамке.

Поиск Gemini по содержимому картинки не гарантирует нахождения идентичного изображения или первоисточника. Сохраняется **«Передать в приложение…»**: системный chooser `ACTION_SEND/image/png`, выбранный пользователем обработчик. Непроверенные внутренние Activity/URL Lens не используются. Если подходящего обработчика нет, **«Сохранить фрагмент»** записывает PNG в `Pictures/ScreenTranslator` через MediaStore. Затем откройте Google/Chrome, нажмите Lens, если он доступен, и выберите изображение. Разрешение на чтение всей галереи не запрашивается.

Браузер и chooser открываются из видимой Activity. После перехода поиск закрывается; при возврате нет старого полноэкранного overlay. Поворот, изменение размера, выход на домашний экран и остановка сессии закрывают старый снимок; для нового выделения повторите долгое нажатие.

## Состояние, сеть и приватность

Один MediaProjection и один VirtualDisplay используются в пределах сессии, захват запускается по жесту. Старое согласие после остановки/перезапуска не восстанавливается; нет START_STICKY, запуска при загрузке, root или AccessibilityService. Остановка доступна в приложении, уведомлении, системном индикаторе, а также происходит при блокировке телефона. Поворот, смена языка/режима/ключа и закрытие результата отменяют текущую операцию и исключают поздние ответы.

Gemini использует только REST `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3.5-flash-lite:generateContent`, заголовок `x-goog-api-key`, OkHttp и Kotlin Serialization. Схема Interactions, параметры temperature/topP/topK и резервная модель не используются. Тайм-ауты: подключение 15 с, запись 30 с, чтение 60 с, весь вызов 90 с. Только HTTP 5xx допускает один повтор через 500 мс; 429, ошибки сети/ключа и тайм-аут не повторяются автоматически. Отмена coroutine отменяет OkHttp Call, в том числе во время чтения тела. Redirect запрещён, ключ не передаётся другому адресу. Ошибки API заменяются фиксированными сообщениями без сырого ответа/ключа.

Изображения уменьшаются до 1600 пикселей по большей стороне, JPEG 85, не более 1,5 МБ до Base64. Максимальный JSON-запрос 3 МиБ, ответ 2 МиБ. OCR, подготовка bitmap, сеть и разбор ответов выполняются вне главного потока. Кэш переводов в памяти ограничен 128 записями; ключ содержит провайдера, модель, оба языка и исходный текст. При остановке кэш очищается.

Снимки, распознанный текст, ответы и ключ не пишутся в обычные логи. Снимки и результаты сохраняются в памяти, кроме явных действий передачи/сохранения фрагмента. При закрытии поиска ссылки UI сбрасываются; bitmap освобождается после завершения использующих его View/RenderThread/SDK. ML Kit может отправлять диагностические данные согласно условиям Google.

FileProvider открывает только `cache/screen-search/`, выдаёт временное чтение одного URI и запрещает запись. Фрагмент доступен получателю для новых открытий до 24 часов. Очистка запускается при старте сессии, новой передаче и периодической системной задачей; даже при задержке удаления провайдер отклоняет просроченный URI. Внешнее приложение может сохранить собственную копию. Постоянное сохранение в галерею — отдельное действие.

Защищённые `FLAG_SECURE`/DRM экраны могут быть пустыми; обходов нет. Мелкий, наклонённый, смешанный текст, особенности вырезов, складные и внешние дисплеи требуют проверки на устройстве. Машинный перевод может ошибаться. Атрибуция соответствует выбранному провайдеру; библиотеки и ссылки — [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Сборка и проверки

Нужны JDK 17, Android SDK Platform 35, Build Tools 35.0.0 и platform-tools. Закреплены Gradle 8.11.1, AGP 8.9.2, Kotlin/Compose compiler 2.1.20, Compose BOM 2025.04.01. Wrapper включён и проверяет SHA-256 дистрибутива.

```bash
export JAVA_HOME=/путь/к/jdk-17
export ANDROID_HOME=/путь/к/android-sdk
"$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --licenses
"$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" \
  'platforms;android-35' 'build-tools;35.0.0' 'platform-tools'
./gradlew --no-daemon :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

Вместо ANDROID_HOME можно задать `sdk.dir` в игнорируемом `local.properties`; Windows использует `gradlew.bat`. Настоящий Gemini-ключ не нужен. Сетевые тесты используют локальный MockWebServer и фиктивную строку ключа.

- APK: `app/build/outputs/apk/debug/app-debug.apk`, debug-подпись создаётся автоматически.
- Lint: `app/build/reports/lint-results-debug.html`.
- Тесты: `app/build/reports/tests/testDebugUnitTest/index.html`.
- Для оптимизированного APK: `./gradlew --no-daemon :app:assembleRelease`. Включены R8/resource shrinking; `app-release-unsigned.apk` требует личной release-подписи для установки.

[Workflow Android APK](.github/workflows/android.yml) собирает APK, lint и unit-тесты на push/pull_request и вручную через Actions → Android APK → Run workflow. Он устанавливает актуальные cmdline-tools, platform-tools, platforms;android-35 и build-tools;35.0.0. Устаревший SDK-пакет `tools` не устанавливается. API-ключи и GitHub Secrets не требуются. В успешном запуске доступны артефакты `ScreenTranslator-debug` и `ScreenTranslator-reports`; debug APK не публикуется автоматически в Releases.

Проверки текущей версии, ограничения среды и полный чек-лист Android 15 — [GEMINI_VALIDATION.md](GEMINI_VALIDATION.md). [VALIDATION.md](VALIDATION.md) и [SEARCH_VALIDATION.md](SEARCH_VALIDATION.md) описывают прежние версии и не подтверждают Gemini. Не считайте mock-тесты подтверждением доступности модели или качества реального перевода.
